# 移动端 Vue3 框架改造总结

## 概述

将原有的桌面端 Vue3 + Vite + TypeScript 项目改造为适配移动端开发的框架，包含移动端布局、px→vw 自动转换、底部 TabBar 导航、安全区域适配等能力。

---

## 改造内容

### 1. `index.html` — 移动端 Meta 配置

- 禁止缩放：`user-scalable=no`
- 安全区域适配：`viewport-fit=cover`
- iOS WebApp 支持：`apple-mobile-web-app-capable`
- 禁止电话号码检测：`format-detection=telephone=no`
- 语言设为 `zh-CN`

### 2. `vite.config.ts` — PostCSS px→vw 自动转换

- 安装并配置 `postcss-px-to-viewport-8-plugin`
- 设计稿宽度 375px，自动将 px 转为 vw 单位
- 排除 `node_modules` 目录

### 3. `src/assets/base.css` — 移动端 CSS 变量体系

- 完整的色彩系统（主题色、成功/警告/危险色）
- 间距、圆角、字体尺寸变量
- 底部安全区域适配：`env(safe-area-inset-bottom)`
- 全局 Reset（清除移动端默认样式）
- 通用工具类（文本省略等）

### 4. `src/assets/main.css` — 移动端布局样式

- Flex 纵向布局容器
- 有/无 TabBar 的页面内容区（滚动 + 安全区）
- 通用卡片样式
- Retina 1px 边框方案

### 5. `src/App.vue` — 底部 TabBar 布局

- 顶部 RouterView + 底部 TabBar 的结构

### 6. `src/components/TabBar.vue` — 底部导航栏

- 4 个 Tab：首页、分类、购物车、我的
- 激活态高亮，路由联动
- 安全区域适配

### 7. 5 个移动端页面视图

| 文件 | 页面 | 功能 |
|------|------|------|
| `HomeView.vue` | 首页 | 搜索栏、轮播图、功能入口、商品网格 |
| `CategoryView.vue` | 分类页 | 左侧分类 + 右侧内容 |
| `CartView.vue` | 购物车 | 选择/数量/结算 |
| `MineView.vue` | 个人中心 | 用户信息、订单、菜单 |
| `DetailView.vue` | 商品详情 | 图片、信息、规格、底部操作栏 |

### 8. 路由配置

- 5 个路由全部懒加载
- 新增分类、购物车、我的、详情页路由

### 9. 清理

- 删除所有桌面端示例组件和图标
- 删除旧的 About 页面
