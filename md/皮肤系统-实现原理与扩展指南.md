## 1. 系统总览

### 1.1 它解决什么问题

把「品牌换肤」从**逐页面 `:deep(.van-xxx)` 覆写**收敛为**单一全局皮肤**，达到：

- 一次接入、全站生效，无需在每个页面重复写 Vant 覆写；
- 运行时一键换肤、即时生效、**无需重新构建**；
- 「快速撤销」= 移除一个 `<html>` 上的 class，全站回退默认主题；
- 支持**多套主题**（不仅是 PICC 红，还有 Vant 蓝 / 翡翠绿 / 暗夜 等共 18 套）。

### 1.2 两套皮肤的分工

| 类型 | 作用域 class | 实现文件 | 覆盖内容 |
|---|---|---|---|
| **品牌皮肤（PICC）** | `html.picc-skin` | `src/styles/vant-picc.css` | Vant4 **全部组件**的重组件主题（PILL 主按钮、红渐变 NavBar、卡片圆角、各组件品牌红…）+ 页面级辅助类 |
| **主题皮肤（其余 17 套）** | `html.theme-<id>` | `src/styles/skins.css` | 仅覆写「主色 + 表面 + 渐变」等 **token**，组件形态回落 Vant 默认，靠主色变量翻转 |

> 关键认知：**PICC 是「重写组件形态」的皮肤；其余主题是「只换主色 token」的皮肤。**
> 这就是为什么 PICC 用独立的 `vant-picc.css`，而其它主题只需要 `skins.css` 里几行 `--van-primary-color`。

### 1.3 文件地图

| 文件 | 角色 | 作用域 | 是否随开关移除 |
|---|---|---|---|
| `src/styles/base-mobile.css` | 常驻中性层：移动端外壳 + 中性布局类 + `:root` 默认变量 | 始终生效（无 class 限制） | 否（始终在） |
| `src/styles/vant-picc.css` | PICC 品牌组件皮肤 | `html.picc-skin` | 是（移除 class 即失效） |
| `src/styles/skins.css` | 17 套主题 token + 深色主题全量覆写 + 各主题头部渐变 | `html.theme-<id>` | 是（移除 class 即失效） |
| `src/composables/useSkin.ts` | 多皮肤引擎：注册表 `SKINS`、切换、持久化、调试 API | JS 运行时 | —（逻辑，无样式） |
| `src/composables/usePiccSkin.ts` | **旧版二值皮肤**（仅 PICC 开/关），已废弃 | — | —（勿在新代码使用） |
| `src/views/vant/MineView.vue` | 皮肤切换面板 UI（色卡网格） | — | — |
| `src/main.ts` | 引入顺序 + 启动 `initSkin('picc')` | — | — |

### 1.4 生效机制（一句话）

> 皮肤 = 一组 CSS 变量集合，挂到 `<html>` 的某个 class 上；
> Vant 组件和业务组件都只引用变量（如 `--van-primary-color`、`--app-bg`），
> 切换 `<html>` 上的 class 即切换变量取值，从而整站换肤。

## 2. 实现原理

### 2.1 三层样式与引入顺序（`src/main.ts`）

```ts
// main.ts（节选，顺序很重要）
import './assets/main.css'          // Vant 基础样式
import './styles/base-mobile.css'   // ① 常驻中性层（先于皮肤，供两套皮肤共用骨架）
import './styles/vant-picc.css'     // ② PICC 品牌皮肤（仅 html.picc-skin 生效）
import './styles/skins.css'         // ③ 主题皮肤（仅 html.theme-<id> 生效）
// ……vant toast/dialog 样式等……
initSkin('picc')                    // ④ 启动时应用默认皮肤（PICC）
```

顺序约束：

- `base-mobile.css` 必须在 `vant-picc.css` / `skins.css` **之前**，否则 PICC 的 `html.picc-skin` 规则无法覆盖中性版默认值。
- `vant-picc.css` 必须在 `skins.css` **之前**（PICC 走 `picc-skin`、主题走 `theme-*`，二者 class 互斥，实际不会冲突，但保持此顺序最稳妥）。

### 2.2 `base-mobile.css`：常驻中性层

作用：**与皮肤开关无关、始终生效**，解决「切到非 PICC 皮肤时页面骨架错乱」。

包含三类内容：

1. `:root` 下定义**应用级语义变量**的默认值（浅色 / Vant 蓝基调）：

   ```css
   :root {
     --app-primary-deep: #1565c0;   /* Vant 深蓝（渐变深端 / 按下态） */
     --app-primary-light: #e8f3ff;
     --app-primary-rgb: 25, 137, 250;
     --app-login-gradient: linear-gradient(180deg, #eef6ff 0%, #e3f0ff 40%, #f0f5fb 100%);

     --app-bg: #f5f6f8;   /* 画布 / 页面底色 */
     --app-surface: #ffffff;
     --app-surface-2: #f7f8fa;
     --app-text: #1a1a1a;
     --app-text-2: #646566;
     --app-text-3: #969799;
     --app-border: #ebedf0;
   }
   ```

2. `#app` 移动端外壳（覆盖 create-vue 桌面脚手架的 `#app{max-width:1280px}`，移动优先、桌面下手机宽度居中预览）。

3. **中性布局类**（两套皮肤通用的灰底画布、白卡、分组标题、暖提示）：
   如 `.picc-page` / `.picc-card` / `.picc-header-gradient` / `.picc-price` / `.picc-notice-warm` 等。
   - 这些类在 `base-mobile.css` 里是「中性默认」（如 `.picc-header-gradient` 在 Vant 皮肤下是蓝渐变、白字可读）；
   - PICC 皮肤下由 `vant-picc.css` 的 `html.picc-skin` 规则**覆盖**为品牌红渐变；
   - 其它主题下由 `skins.css` 的 `html.theme-<id> .picc-header-gradient` **覆盖**为该主题渐变。
   - **品牌色只允许存在于 `vant-picc.css` 的 `html.picc-skin` 作用域**，保证「移除 picc-skin = 回退默认主题」机制不被破坏。

### 2.3 `vant-picc.css`：PICC 品牌组件皮肤

仅当 `<html class="picc-skin">` 存在时生效。结构分 5 段：

| 段 | 内容 |
|---|---|
| 1. 设计 Token | `--picc-primary:#d71920`、`--picc-primary-deep:#a91218`、中性灰、表面、语义色、圆角尺度、字族等（`html.picc-skin` 作用域） |
| 2. 全局基础变量覆写 | 把 Vant 的 `--van-primary-color` 等覆盖为 PICC 红；同时把 `--app-primary-*`、`--app-login-gradient` 覆盖为红系（覆盖 `:root` 的蓝系默认值） |
| 3. 组件级覆盖 | 对 Vant4 各组件做细粒度覆写（见 §5） |
| 4. PICC 特色增强 | Toast / Notify 品牌色等 |
| 5. 页面级辅助类 | `.picc-page` / `.picc-card` / `.picc-header-gradient` / `.picc-price` / `.picc-number-display` / `.picc-notice-warm` / `.picc-section-title`（见 §6） |

品牌要点（v2.0）：

- **主 CTA 按钮 PILL 全圆角** `9999px`、高度 `48px`、带红色投影；
- **NavBar 红色渐变变体**：给 `van-nav-bar` 加 class `van-nav-bar--picc-primary` 即获红底白字渐变（默认 NavBar 仍为白底黑字）；
- 卡片 `12px`、输入框 `8px`、选中态一律品牌红。

### 2.4 `skins.css`：主题 token

每种主题一个 `html.theme-<id>` 块，**浅色主题**只覆写主色配套：

```css
html.theme-emerald {
  --van-primary-color: #059669;
  --van-primary-color-light: #d1fae5;
  --van-primary-color-light-2: #a7f3d0;
  --app-primary-deep: #047857;
  --app-primary-light: #d1fae5;
  --app-primary-rgb: 5, 150, 105;
  --app-login-gradient: linear-gradient(180deg, #ecfdf5 0%, #d1fae5 40%, #f0fdf9 100%);
}
```

再通过 `html.theme-<id> .picc-header-gradient` 把品牌头部渐变翻成该主题色（如 `html.theme-emerald .picc-header-gradient { background: linear-gradient(135deg,#065f46,#059669); color:#fff; }`）。

**深色主题**（`dark` / `luxury` / `navy`，`SKINS` 中 `dark:true`）除主色外，还需**全量覆写表面与文本**让画布 / 卡片 / 文字跟随翻转，例如：

```css
html.theme-dark {
  --van-primary-color: #60a5fa;
  /* 表面 / 文本 / 边框 深色化 */
  --van-background: #0f172a; --van-text-color: #f8fafc; --van-border-color: #334155;
  /* 应用级语义变量同步深色 */
  color-scheme: dark;
  --app-bg: #0f172a; --app-surface: #1e293b; --app-text: #f8fafc; --app-border: #334155;
  /* 按钮文字在深色主色下改深色保证对比度 */
  --van-button-primary-color: #0f172a;
  /* Vant 各组件背景 / 文本 token */
  --van-nav-bar-background: #111827; --van-cell-background: #1e293b; --van-popup-background: #1e293b; /* …… */
}
html.theme-dark #app { background: #0f172a; }
html.theme-dark .picc-card { background: #1e293b; box-shadow: none; border: 1px solid #334155; }
```

> 新增深色主题时，**必须**像 `dark` 那样把 `--app-*`、`--van-background*`、`--van-text-color*`、`--van-border-color`、`--van-*-background` 等一整套覆写齐全，否则会残留白底 / 黑字。

### 2.5 皮肤引擎 `useSkin.ts`（多皮肤注册表）

```ts
// 注册表：顺序即面板展示顺序
export const SKINS: SkinMeta[] = [
  { id: 'picc',     name: 'PICC 品牌红', desc: '人保财险官方品牌', color: '#d71920', deep: '#a91218' },
  { id: 'vant',     name: 'Vant 默认蓝', desc: '清爽蓝调',         color: '#1989fa', deep: '#1565c0' },
  { id: 'emerald',  name: '翡翠绿',     desc: '清新自然',         color: '#059669', deep: '#047857' },
  /* …… 共 18 套，见下方完整清单 …… */
  { id: 'dark',     name: '暗夜',       desc: '护眼深色', color: '#60a5fa', deep: '#0f172a', dark: true },
  { id: 'luxury',   name: '奢华黑金',   desc: '高端黑金', color: '#eab308', deep: '#0a0a0a', dark: true },
  { id: 'navy',     name: '商务深蓝',   desc: '深海军蓝', color: '#93c5fd', deep: '#0a1628', dark: true },
]
```

`SkinMeta` 接口：

```ts
export interface SkinMeta {
  id: string        // 唯一标识，决定 class 名 theme-<id>（picc 特例为 picc-skin）
  name: string      // 展示名
  desc: string      // 描述
  color: string     // 主色，用于面板色卡与当前指示点
  deep: string      // 深端色，用于色卡渐变预览
  dark?: boolean    // 是否为深色主题（影响面板/是否需全量覆写）
}
```

核心逻辑：

```ts
const THEME_PREFIX = 'theme-'
const active = ref<string>('picc')   // 全局单例，所有调用方共享

function applyClasses(id: string) {
  const cl = document.documentElement.classList
  // 先清除所有旧皮肤 class，避免多套叠加冲突
  Array.from(cl)
    .filter((c) => c.startsWith(THEME_PREFIX) || c === 'picc-skin')
    .forEach((c) => cl.remove(c))
  // PICC 特例用 picc-skin；其它用 theme-<id>
  if (id === 'picc') cl.add('picc-skin')
  else cl.add(THEME_PREFIX + id)
}

function setSkin(id: string) {            // 切换（非法 id 回落 PICC）
  if (!SKINS.some((s) => s.id === id)) id = 'picc'
  active.value = id
  applyClasses(id)
  persist(id)                            // 写 localStorage
}

function init(defaultSkin = 'picc') {    // 启动恢复
  const stored = localStorage.getItem('app-skin')
  const id = stored && SKINS.some((s) => s.id === stored) ? stored : defaultSkin
  active.value = id
  applyClasses(id)
}

export function useSkin() {
  return { active, setSkin, init, current, SKINS }
}
export function initSkin(defaultSkin = 'picc') { useSkin().init(defaultSkin) }
```

持久化：写 `localStorage['app-skin']`（当前 id），并同步旧键 `localStorage['picc-skin-enabled']`（`'1'` / `'0'`，兼容仍依赖它的代码 / 测试）。

浏览器调试入口：

```ts
window.__skin = {
  get active() { return active.value },   // 当前皮肤 id
  set: (id) => useSkin().setSkin(id),     // 切换
  list: () => SKINS,                      // 列出全部皮肤
}
```

### 2.6 级联优先级与「快速撤销」原理

| 选择器 | 特异性 | 说明 |
|---|---|---|
| `:root`（base-mobile 默认变量） | (0,1,0) | 最低，作为兜底默认值 |
| `html.picc-skin` / `html.theme-<id>` | (0,1,1) | 主题 / 品牌作用域，覆盖 `:root` |
| `html.theme-<id> .picc-header-gradient` | (0,2,1) | 更具体，覆盖同级 `.picc-header-gradient` |

- **快速撤销**：`setSkin('vant')` 会先 `remove('picc-skin')` 再加 `theme-vant`；或直接 `document.documentElement.classList.remove('picc-skin')`。PICC 的所有 `html.picc-skin` 规则随之失效，组件回落 Vant 默认主题，**无需重新构建**。
- 同一时刻仅一个皮肤 class 生效（`applyClasses` 切换时清空其它皮肤 class），互不冲突。

## 3. 引入与使用方法

### 3.1 本项目（已接入）

`main.ts` 已接线，无需额外操作：

```ts
import './styles/base-mobile.css'
import './styles/vant-picc.css'
import './styles/skins.css'
// ……
initSkin('picc')   // 启动即应用 PICC 品牌皮肤
```

### 3.2 在代码里切换 / 读取皮肤

```ts
import { useSkin } from '@/composables/useSkin'

const { active, setSkin, current, SKINS } = useSkin()

setSkin('emerald')                 // 切换到翡翠绿
setSkin('dark')                    // 切换到暗夜（深色）
console.log(active.value)          // 当前 id
console.log(current.value.name)    // 当前皮肤展示名（computed）
console.log(current.value.dark)    // 是否为深色主题
```

### 3.3 在 UI 里切换（皮肤面板，参考 `MineView.vue`）

`MineView.vue` 的「皮肤设置」面板用 `SKINS` 直接渲染色卡网格，点击调 `setSkin`：

```vue
<van-popup v-model:show="skinShow" position="bottom" round>
  <div class="skin-grid">
    <button
      v-for="s in SKINS" :key="s.id"
      class="skin-item" :class="{ 'skin-item--active': s.id === active }"
      :aria-pressed="s.id === active"
      @click="setSkin(s.id)"
    >
      <span class="skin-swatch" :style="{ background: `linear-gradient(135deg, ${s.color}, ${s.deep})` }"></span>
      <span class="skin-name">{{ s.name }}</span>
    </button>
  </div>
</van-popup>
```

> 复制此面板到任何需要换肤入口的页面即可（本质是遍历 `SKINS` + 调 `setSkin`）。

### 3.4 浏览器控制台即时调试

```js
window.__skin.active          // 读取当前 id
window.__skin.set('luxury')   // 切换
window.__skin.list()          // 列出全部皮肤 meta
```

### 3.5 接入一个全新项目

CSS 资产（`vant-picc.css`、`skins.css`、`base-mobile.css`）可从此项目或 `vant-picc-skin` 技能目录复制。引擎有两种选择：

**方案 A（推荐，沿用本项目多皮肤引擎）：**

1. 复制 `vant-picc.css`、`skins.css`、`base-mobile.css` 到新项目 `src/styles/`；
2. 复制 `src/composables/useSkin.ts` 到新项目；
3. 在 `main.ts` 按 §2.1 顺序引入三个 CSS，并调用 `initSkin('picc')`；
4. 业务里用 `useSkin()` 切换、用 §3.3 的面板做 UI。

**方案 B（仅要 PICC 品牌皮肤，不需要多主题）：**
用 `vant-picc-skin` 技能的 `assets/setup.mjs`（复制 `vant-picc.css` + 旧版 `usePiccSkin.ts` 并注入 `main.ts`，调用 `initSkin(true)`）。注意：本项目已升级为 `useSkin` 多皮肤引擎，**新代码请统一用 `useSkin`，不要再引入旧的 `usePiccSkin`**。

### 3.6 页面 / 组件里如何引用 Token（不要写死颜色）

- 用皮肤提供的变量而非硬编码：
  - 主色 → `var(--van-primary-color)`（自动随皮肤翻转）；
  - 页面装饰红 → `var(--picc-primary)`（仅 PICC 下存在，需写在 `html.picc-skin` 或确认作用域）；通用装饰红建议用 `var(--van-primary-color)`；
  - 画布 / 表面 / 文字 / 边框 → `var(--app-bg)` / `var(--app-surface)` / `var(--app-text)` / `var(--app-border)`；
  - 渐变头 → `var(--app-login-gradient)`；
  - 半透明主色 → `rgba(var(--app-primary-rgb), 0.18)`。
- 需要品牌氛围时直接用页面级辅助类（见 §6），如 `<div class="picc-card">`、`<div class="picc-header-gradient">`。

## 4. 后续如何添加 / 删除 / 修改皮肤（核心）

> 黄金法则：**改样式只在 CSS 文件里动；改「有哪些皮肤」只在 `useSkin.ts` 的 `SKINS` 里动；两者必须同步。**

### 4.1 新增一套浅色主题（例如「日落橙 `sunset`」）

**第 1 步：`src/composables/useSkin.ts` 注册表追加一项**

```ts
export const SKINS: SkinMeta[] = [
  // ……现有……
  { id: 'sunset', name: '日落橙', desc: '温暖日落', color: '#fb7185', deep: '#f43f5e' },
]
```

**第 2 步：`src/styles/skins.css` 追加 `html.theme-sunset` 块（主色 + 表面 + 头部渐变）**

```css
/* ===================== 日落橙（温暖日落 / Sunset） ===================== */
html.theme-sunset {
  --van-primary-color: #fb7185;
  --van-primary-color-light: #ffe4e6;
  --van-primary-color-light-2: #fecdd3;
  --app-primary-deep: #f43f5e;
  --app-primary-light: #ffe4e6;
  --app-primary-rgb: 251, 113, 133;
  --app-login-gradient: linear-gradient(180deg, #fff1f2 0%, #ffe4e6 40%, #fff7f8 100%);
}
html.theme-sunset .picc-header-gradient {
  background: linear-gradient(135deg, #f43f5e 0%, #fb7185 100%);
  color: #ffffff;
}
```

**完成**。面板会自动出现「日落橙」，点选即生效；无需改任何组件。

### 4.2 新增一套深色主题

### 4.4 修改某套皮肤配色

仅改 `skins.css` 对应 `html.theme-<id>` 块的变量值即可（如把翡翠绿主色从 `#059669` 改为 `#10b981`）。`SKINS` 里的 `color`/`deep` 是面板色卡，记得同步改，避免面板与实际不符。

### 4.5 修改 PICC 品牌风格本身（改红 / 改按钮形态）

全部在 `src/styles/vant-picc.css` 的 `html.picc-skin` 作用域内：

- 换品牌红：改 `html.picc-skin` 下的 `--picc-primary`、`--van-primary-color`（两处都要改，保持同步）；
- 改主按钮圆角：搜索 `.van-button--primary` 相关覆写，改 `border-radius`；
- 改卡片圆角：改 `--picc-radius-lg` 或 `.picc-card` 的 `border-radius`；
- 改 NavBar 红渐变：改 `.van-nav-bar--picc-primary` 的 `background`。

> 所有 PICC 专属样式**必须包在 `html.picc-skin` 作用域**，否则会破坏「移除 class 即回退」的能力。

### 4.6 给 PICC 皮肤新增某组件的覆写

在 `vant-picc.css` 的「3. 组件级覆盖」段、对应组件注释下追加，且**必须包在 `html.picc-skin`**：

```css
/* --- 假设要覆写 van-tag --- */
html.picc-skin .van-tag--primary {
  background: var(--picc-primary);
  border-radius: var(--picc-radius-full);
}
```

需要覆盖 inline 注入变量时用 `!important` 兜底，例如 `html.picc-skin .van-slider__bar { background: var(--picc-primary) !important; }`。

### 4.7 修改默认皮肤

改 `src/main.ts` 的 `initSkin('picc')` 参数，例如默认用暗夜：`initSkin('dark')`。持久化用户选择会覆盖默认值（用户选过则下次以 localStorage 为准）。

### 4.8 新增 / 修改页面级辅助类（`.picc-*`）

- 中性、两套皮肤都需要的：加在 `base-mobile.css`（如新增 `.picc-divider`）；
- 仅 PICC 品牌视觉的：加在 `vant-picc.css` 的「5. 页面级辅助类」段（包 `html.picc-skin`）；
- 若希望其它主题也有对应视觉：在 `skins.css` 追加 `html.theme-<id> .你的类`。

### 4.9 新增 / 修改应用级语义变量（`--app-*`）

- 浅色默认值：在 `base-mobile.css` 的 `:root` 定义；
- PICC 下取值：在 `vant-picc.css` 的 `html.picc-skin` 内覆盖；
- 深色主题下取值：在 `skins.css` 的 `html.theme-<darkid>` 块内覆盖（确保 `dark:true` 的主题都覆盖到，否则暗色下变量不一致）。

### 4.10 修改皮肤名称 / 描述 / 面板色卡

仅改 `useSkin.ts` 的 `SKINS` 中对应 `name` / `desc` / `color` / `deep`。这些只影响「皮肤面板展示」与 `current.value` 的取值，不影响样式（样式由 class 决定）。

## 8. 快速验证与排错

### 8.1 验证当前皮肤

```js
window.__skin.active          // 当前 id 字符串
document.documentElement.className   // 应只含一个皮肤 class：picc-skin 或 theme-<id>
localStorage.getItem('app-skin')     // 持久化的当前 id
```

### 8.2 常见问题

| 现象 | 原因 | 修复 |
|---|---|---|
| 切到非 PICC 后头部白底白字、排版错乱 | `base-mobile.css` 未引入或顺序在皮肤之后 | 确保 `base-mobile.css` 在 `vant-picc.css` / `skins.css` **之前**引入 |
| 暗色主题下某卡片仍是白底 | 该组件没引用 `--app-surface`，或深色块漏覆写 `--van-*-background` | 在 `skins.css` 的 `theme-<id>` 块补齐对应 `--van-*-background` / `--app-surface` |
| PICC 品牌红没生效 | 相关样式写在全局非 `html.picc-skin` 作用域，或 `vant-picc.css` 未引入 | 确认 `initSkin('picc')` 与 CSS 引入；PICC 样式必须 `html.picc-skin` 作用域 |
| 新增主题面板不显示 | 只改了 `skins.css` 没改 `SKINS`，或反之 | 两者必须同步（见 §4.1） |
| 切换皮肤后样式残留（多套叠加） | 切换时未清旧 class | 用 `setSkin()` / `initSkin()`，它们内部会 `remove` 所有旧皮肤 class |
| 组件里硬编码了 `#1989fa` / `#ee0a24` | 旧代码写死 Vant 默认色 | 改为 `var(--van-primary-color)` 等 |

## 9. 可用与不可用（Do & Don't）

**Do（推荐）**

- 品牌红严格收束于主 CTA、选中态、保障语义、角标与错误提示；
- 主 CTA 用 PILL 全圆角（`9999px`）、高度 48px、带红色投影；
- 选中态（TabBar、标签、单选 / 复选、开关）一律品牌红；
- 用 `useSkin()` 管理皮肤，状态持久化；
- 业务颜色引用 `--van-primary-color` / `--app-*` 变量；
- 需要品牌氛围直接用页面级辅助类。

**Don't（禁止）**

- 不要在页面里再用 `:deep()` 逐组件覆写 Vant4（应进全局皮肤）；
- 不要把 `#1989fa` / `#ee0a24` 等 Vant 默认色硬编码进新代码；
- 不要把品牌红铺成大面纯色背景（渐变装饰区除外）；
- 不要给主按钮使用非 PILL 圆角；
- 不要为了「临时改色」直接改 `:root` 或全局非作用域样式，这会破坏「快速撤销」；
- 不要在 `html.picc-skin` 作用域**之外**写 PICC 专属样式（撤不干净）；
- 新代码不要引入已废弃的 `usePiccSkin`（旧二值皮肤），统一用 `useSkin`。

## 10. 与 `vant-picc-skin` 技能的关系

- **CSS 资产来源**：`vant-picc.css`、`skins.css` 的 PICC 品牌段源自 `vant-picc-skin` 技能（`md/picc/app-ui/` 官方截图校准）。
- **引擎升级**：技能默认提供的是**二值** `usePiccSkin`（仅 PICC 开/关）。本项目已将其升级为 **`useSkin` 多皮肤注册表**（18 套、可扩展、可持久化），因此：
  - 引入新项目时，PICC 的 CSS 可直接来自技能，但**皮肤引擎请用本项目的 `useSkin`**（多主题能力更强）；
  - 若使用技能 `setup.mjs`，它会安装旧版 `usePiccSkin`（仅 PICC）。本项目不依赖它，旧文件 `src/composables/usePiccSkin.ts` 仅保留给历史测试，**新代码勿用**。
- **完整设计规格**：见技能内 `DESIGN-VANT.md`（或 `references/tokens.md`）的 Vant4 CSS 变量 → PICC 取值全量表。
